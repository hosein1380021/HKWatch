# HKWatch — نمونه اولیه

این برنامه فقط برای پیدا کردن دستگاه‌های Bluetooth Low Energy، اتصال و نمایش UUID سرویس‌هاست. اطلاعات تب سیستم بر اساس گفته کاربر نوشته شده‌اند و از ساعت خوانده نمی‌شوند. هیچ تغییر یا به‌روزرسانی فریم‌وری انجام نمی‌دهد.

## ساخت با GitHub Actions
1. یک مخزن جدید GitHub بسازید و محتوای این پوشه را در ریشه مخزن قرار دهید. پوشه مخفی `.github` را هم حتماً آپلود کنید؛ فایل workflow باید در مسیر `.github/workflows/build.yml` باشد.
2. در تب Actions، workflow با نام Build unsigned iOS app را اجرا کنید (یا پس از push به شاخه main اجرا می‌شود).
3. پس از موفقیت، artifact به نام HKWatch-unsigned را دانلود و از فایل zip خارج کنید. فایل داخل آن IPA بدون امضاست و مستقیماً قابل نصب نیست.
4. از ابزار سازگار با iOS و ویندوز مانند Sideloadly یا AltStore برای امضا با Apple ID و نصب استفاده کنید. پشتیبانی از نسخه iOS و محدودیت حساب رایگان را پیش از نصب در مستندات همان ابزار بررسی کنید. حساب رایگان معمولاً به تمدید امضا پس از هفت روز نیاز دارد. ممکن است Developer Mode لازم شود.
5. روی آیفون واقعی مجوز Bluetooth بدهید و جست‌وجو کنید. دستگاه صوتی Call ممکن است اتصال جداگانه باشد. اگر اتصال برقرار نشد، Wearfit Pro را موقتاً قطع کنید.

این کد در محیط فعلی با Xcode کامپایل یا روی دستگاه تست نشده است. قابلیت‌های سلامتی، اعلان‌ها، باتری، واچ‌فیس و سیستم‌عامل هنوز پیاده‌سازی نشده‌اند. iOS آدرس MAC دستگاه BLE را در اختیار اپ قرار نمی‌دهد.
